# 问卷管理端页面与交互设计计划（参考调问网）

> 状态：参考调研 + 设计稿（2026-11-28）。
> 调研方式：登录参考项目，只读浏览现有「测试问卷」，未新建、修改、发布或删除任何数据。
> 相关文档：[tdesign-ng 组件现状与改造优先级](tdesign-ng-component-priority.md)、[技术可行性评估](technical-feasibility-assessment.md)。

## 1. 调研对象与限制

用现有「测试问卷」（设计中、0 份答卷、未发布）走查了以下页面：

| 页面 | 观察结果 |
| --- | --- |
| 我的问卷 | 筛选 + 表格 + 分页，行操作较多 |
| 问卷设计 | 顶部上下文导航 + 题型/画布/设置三栏 |
| 数据统计 | 概览卡 + 统计/原始数据子页签，0 答卷时图表为空 |
| 答卷收集 | 答卷链接、复制/打开、二维码下载 |
| 原始数据 | 时间/IP/城市筛选 + 导出 + 数据表格 |
| 公开填写页 | 问卷未发布，仅显示「问卷未开启」 |

限制说明：

- 该问卷没有题目且未发布，无法观察真实题目卡片和公开填写体验；为遵守只读要求，没有添加题目或发布。
- 只借鉴功能、信息架构和上下布局，不借鉴其 Element Plus 视觉和左侧全局菜单；样式统一使用 TDesign。
- 路由和 URL 结构完全按本项目规范设计，不照搬参考项目的地址形式。
- 「上下布局」指参考项目的「上下经典布局」：顶部 header，下方内容区；编辑器内部仍可按题型/画布/设置分栏，不引入全局左侧导航。

## 2. 参考页面拆解

### 2.1 我的问卷（列表）

信息结构：

1. 筛选区：问卷标题输入框、状态下拉框、重置/查询。
2. 标题区：「我的问卷」+「新建问卷」。
3. 表格列：复选框、问卷、答卷数、状态、创建时间、操作。
4. 分页：页码 + 每页条数。
5. 行操作：设置、编辑、分享、数据、查看、删除（图标按钮）。

可借鉴点：

- 列表突出「答卷数 + 状态 + 创建时间」，比只看更新时间更贴近运营视角。
- 行操作多，适合用 TDesign Dropdown 收敛，危险操作单独确认。
- 支持勾选做批量操作，但 MVP 可以先不做。

### 2.2 问卷设计（编辑器）

顶部：

- Logo/返回入口、问卷标题、切换布局按钮。
- 问卷上下文菜单：我的项目、数据统计、答卷收集、问卷设计。
- 设计/收集/数据围绕同一份问卷切换，而不是回到全局列表。

主体三栏：

| 区域 | 内容 |
| --- | --- |
| 左栏（窄） | 常用题型 / 更多题型；单选题、多选题、排序题等题型卡片；基本题型、矩阵扩展、辅助组件、功能事件分组；底部发布/保存 |
| 中栏（宽） | 大纲 / 题库页签；画布内显示问卷标题、说明、空状态提示、「增加新题」 |
| 右栏（窄） | 问卷设置 / 题目设置页签；一页一题、回答限制、计分属性等 |

其他细节：

- 题库页签按「满意度、个人信息」等分类展示预置题卡，点击或拖拽加入。
- 空画布有明确引导文案，避免用户不知道下一步。
- 发布/保存固定在题型面板底部，操作路径短。

### 2.3 数据统计（默认统计）

- 问卷标题 + 状态下拉框。
- 一级页签：问卷设计 / 问卷收集 / 问卷数据。
- 二级页签：默认统计 / 原始数据。
- 概览卡：状态、收集数、创建时间。
- 图表区：0 答卷时为空。

启示：统计页先做「概览 + 空状态」，再按题型补图表；不要一开始做复杂图表配置。

### 2.4 答卷收集（答卷地址）

- 问卷标题 + 状态；一级页签同上。
- 二级页签：答卷地址 / 网站组件。
- 只读答卷链接 + 「复制地址」+「打开问卷」。
- 二维码区域 + 下载二维码。
- 未发布时链接不可用（参考问卷当前为设计中）。

启示：我们已有公开填写地址，可直接复用；二维码可前端生成，也可以由 API 返回。

### 2.5 原始数据

- 概览卡：状态、收集数、创建时间。
- 筛选区：导出数据、开始/结束日期、IP、城市、重置/查询。
- 表格列：复选框、序号、答卷 IP、地区、回答时间、用时、回答题数、操作。
- 空状态：「暂无数据，共 0 条」。

启示：数据页的核心是筛选、分页、导出；MVP 先做时间范围 + IP + 表格，再补地区和导出任务。

### 2.6 公开填写页

- 当前问卷未发布，只显示「问卷未开启」。
- 无法在不发布的前提下观察正常填写态；我们已有公开填写页，可作为后续对比基线。
- 需要补「未发布/已下线」的友好提示，而不是直接暴露接口错误。

## 3. 与当前实现的差距

| 模块 | 当前实现 | 参考项目 | 建议 |
| --- | --- | --- | --- |
| 全局外壳 | 顶部菜单 + 下方内容 | 顶部 + 左侧菜单 | 保持上下布局，不引入左侧菜单 |
| 问卷列表 | 搜索、状态筛选、TDesign 表格、分页、编辑/复制/删除 | 额外有答卷数、创建时间、批量选择、更多行操作 | 增加答卷数与创建时间；行操作收进 Dropdown |
| 问卷编辑器 | 单页纵向的分组/题目编辑 | 顶部上下文导航 + 三栏拖拽编辑器 | 分阶段改为「顶部工具栏 + 题型/画布/设置」 |
| 数据统计 | 无 | 概览卡 + 图表 + 空状态 | 新建统计页 |
| 答卷收集 | 编辑器内复制链接 | 独立页面 + 二维码 + 网站组件 | 新建收集页 |
| 原始数据 | 无 | 筛选 + 导出 + 数据表格 | 新建数据页 |
| 公开填写 | 已有 | 未发布时显示「问卷未开启」 | 补未发布/已下线提示 |

## 4. 目标信息架构

```text
/t/:tenantSlug/questionnaires                              问卷列表
/t/:tenantSlug/questionnaires/:questionnaireId             问卷设计（现有入口）
/t/:tenantSlug/questionnaires/:questionnaireId/stats       数据统计
/t/:tenantSlug/questionnaires/:questionnaireId/collect     答卷收集
/t/:tenantSlug/questionnaires/:questionnaireId/responses   原始数据
/t/:tenantSlug/s/:questionnaireId                          公开填写
```

- 路由沿用项目现有的 `/t/:tenantSlug` 租户前缀和 Angular Router 普通路径参数，不使用参考项目的 hash 路由。
- 现有 `/questionnaires/:questionnaireId` 继续作为设计页入口，不额外增加 `/design` 层级，避免旧链接失效。
- 顶部全局菜单仍然是「问卷管理 / 题库」；进入单份问卷后显示问卷上下文 header + 页签。
- 设计页三栏在窄屏下折叠：右栏设置收进 Drawer 或页签，左栏题型变为横向滚动。

## 5. 页面设计要点

### 5.1 问卷列表

- 列：序号、问卷（标题 + slug）、答卷数、状态、版本、创建时间、更新时间、操作。
- 操作：编辑、复制链接、数据、删除；更多操作放 Dropdown。
- 删除使用 Popconfirm/Dialog，文案说明会级联删除版本与回答。

### 5.2 问卷上下文 Header

- 左侧：返回列表、问卷标题、状态标签、未保存提示。
- 中间/下方：页签「设计 / 统计 / 收集 / 数据」。
- 右侧：保存草稿、发布、复制链接（已发布时可用）。

### 5.3 设计页

- 左栏：题型卡片 + 题库入口；底部保存/发布。
- 中栏：大纲 + 画布；空状态引导；分组与题目卡片。
- 右栏：问卷设置/题目设置；一页一题、回答限制、计分等按需逐步补。
- 第一阶段不做拖拽，先提供「点击添加题型」；后续再补排序。

### 5.4 统计页

- 概览卡：状态、收集数、创建时间、最近回答时间。
- 默认统计：按题型输出分布；无数据时显示 Empty。
- 原始数据子页：跳转到数据页。

### 5.5 收集页

- 已发布：显示公开链接、复制按钮、打开问卷、二维码、下载。
- 未发布：显示禁用态和「发布后可收集」提示。
- 网站组件可作为后续扩展，不在 MVP 内。

### 5.6 数据页

- 筛选：时间范围、IP（精确/模糊待定）、城市（后续）。
- 表格：序号、IP、地区、回答时间、用时、回答题数、操作（查看详情）。
- 导出：先同步导出 CSV；数据量大时再改异步任务。

## 6. API 与权限需求

| 能力 | 建议接口 | 权限 |
| --- | --- | --- |
| 列表答卷数 | `GET /t/{slug}/questionnaires` 响应增加 `responseCount` | `survey:read` |
| 统计概览 | `GET /t/{slug}/questionnaires/:id/stats` | `survey:read` |
| 原始数据 | `GET /t/{slug}/questionnaires/:id/responses?page&pageSize&from&to&ip` | `survey:read` |
| 导出 | `GET /t/{slug}/questionnaires/:id/responses/export` | `survey:read`（后续可拆 `response:export`） |
| 收集信息 | 公开地址可由前端拼接；二维码前端生成 | `survey:read` |
| 设计保存/发布 | 现有 draft/publish 接口 | `survey:update` / `survey:publish` |
| 删除 | 现有 DELETE | `survey:delete` |

说明：

- 统计与原始数据必须校验问卷属于当前租户。
- 未发布问卷的公开填写接口继续返回 `questionnaire_not_published`，前端展示友好提示。
- 答卷数建议在列表查询时聚合，避免 N+1。

## 7. TDesign 组件映射

| 页面 | 已可用 | 需要补/验证 |
| --- | --- | --- |
| 列表 | Table、Pagination、Select、Input、Button、Tag、Message | Dropdown、Popconfirm、Table 选择列 |
| 设计页 | Button、Input、Textarea、Tag | Tabs、InputNumber、Upload、DatePicker、Tree/List、Drawer |
| 统计页 | Button、Tag、TMenu、ECharts | Tabs、Statistic、Empty |
| 收集页 | Button、Input、Message、QRCode | Tabs |
| 数据页 | Table、Pagination、Input、Button | DateRangePicker、Checkbox、Popconfirm、导出 |
| 外壳 | Button、Tag、TMenu | Dropdown、Avatar |

已知阻塞：`TCard` 在 npm 0.1.1 中内容投影不渲染，暂用 TDesign 令牌样式面板替代。

图表库已确定为 ECharts（项目没有 TDesign Charts）。统计页按需加载 ECharts，只引入用到的图表类型，避免增大初始包。

二维码已确定优先使用前端 TDesign `TQRCode` 直接生成；只有前端组件无法满足的场景（如服务端批量出图、离线打印）再改用后端生成。

## 8. 分阶段实施计划

| 阶段 | 范围 | 验收 |
| --- | --- | --- |
| 1. 列表增强 | 答卷数、创建时间、行操作 Dropdown、删除确认 | 列表信息与参考项目对齐，移动端可用 |
| 2. 问卷工作区 | 上下文 Header + 设计/统计/收集/数据页签；收集页链接与二维码 | 不返回列表即可在四个页面间切换 |
| 3. 统计与数据 | 概览卡、空状态、按题型统计；原始数据筛选/分页/导出 | 0 答卷与有答卷两种状态都正确 |
| 4. 编辑器三栏 | 题型面板、画布、设置面板；点击添加题型；后续拖拽排序 | 可完成「加题-编辑-保存-发布」全流程 |

## 9. 待确认问题

1. 导出是同步 CSV 还是异步任务？单次导出上限多少？
2. 统计/原始数据对 `viewer` 是否可见，还是只对 `owner/admin/editor` 开放？
3. 现有编辑器是「分组 + 题目」模型，参考项目是扁平题目；大纲如何映射分组？
4. 需要一份已发布、含题目的问卷才能继续观察真实编辑器和公开填写页；需用户侧提供或授权。

## 10. 实施进度（2026-11-28）

已完成：

- 顶部导航改用 TDesign `TMenu`，根据当前路由同步选中态。
- Web 切换为 hash 路由，公开填写链接统一带 `#`。
- 问卷列表增加答卷数、创建时间，删除改为 TDesign 对话框确认。
- 单份问卷增加「设计 / 统计 / 收集 / 原始数据」页签。
- 答卷收集页：已发布时展示链接、复制、打开与前端 `TQRCode` 二维码；草稿状态给出发布引导。
- 数据统计页：展示答卷数、状态、当前版本与最近发布时间；已发布问卷按题型用 ECharts 展示选择题与评分题分布，文本题展示作答数。
- 原始数据页：分页表格 + 按题字段化查看单份答卷 + 导出 CSV（UTF-8 BOM，选择题映射选项文案）。
- API 新增 `GET /t/{slug}/questionnaires/{id}/stats`、`GET .../responses` 与 `GET .../responses/export`，列表返回 `responseCount`；统计响应包含按题聚合的 `questions`。

待继续：

- 原始数据的时间/IP 筛选（IP 需新增采集字段与迁移）。
- 统计页补充多选堆叠、矩阵题等更复杂题型，以及按版本/时间维度筛选。
- 编辑器改为「题型面板 / 画布 / 设置」三栏，并补题目大纲与拖拽排序。
